# Productivity Dashboard

A simple, mobile-friendly task manager and memory system. Tasks and data are stored locally in your browser.

## Features

- **Tasks**: Organize by School, Work, Personal
- **Memory**: Track people, projects, and terms
- **Mobile Friendly**: Works on phone and desktop
- **Offline**: All data stored in browser (localStorage)
- **Export**: Download tasks as JSON backup

## How to Use

1. Open `index.html` in a browser
2. Add tasks using the "Add" buttons
3. Check off completed tasks
4. Switch to Memory tab to track people, projects, and terms
5. Use Export to backup your tasks

## Data

All data is stored in your browser's local storage. It persists across sessions on the same device/browser.

To backup: Click "Export Tasks" to download your tasks as JSON.
